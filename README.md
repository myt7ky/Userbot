# 🔎 Userbot: платный бот для поиска красивых юзов

Telegram-бот, который генерирует красивые юзернеймы, проверяет, свободны ли они, и выдаёт пользователю
свободные. **Первый поиск бесплатный, остальные продаются за Telegram Stars ⭐.**

## Как это выглядит для пользователя
Внизу экрана всегда есть меню:

```
[ 🔎 Найти юз ]   [ ✅ Проверить юз ]
[ 💎 Купить поиски ] [ 👤 Профиль ]
[ ❓ Помощь ]       (+ 🛠 Админка у админа)
```

1. **🔎 Найти юз** → выбор стиля кнопками: 🗣 Читаемые, 📖 Слова, ✨ Слово+, 🔁 Повторы, 🪞 Палиндромы,
   🔢 Слово+цифры, 🎲 Случайные, 🔤 По слову, 🧩 По маске.
2. Бот показывает прогресс (с кнопкой **⏹ Остановить**) и присылает до 5 свободных юзов. Юз копируется нажатием.
3. Когда попытки кончились, бот предлагает пакеты. Оплата звёздами проходит прямо в Telegram, поиски начисляются сразу.

Правила, честные для покупателя:
- Если поиск не нашёл ни одного юза (или упал с ошибкой), попытка **возвращается**.
- Найденные юзы **не показываются другим** пользователям в течение 3 дней.
- **✅ Проверить юз** даёт 10 бесплатных проверок в сутки на юзы, которые человек придумал сам.

## Как бот проверяет юзы
Bot API не умеет проверять, свободен ли юзернейм, поэтому бот спрашивает через **ваш обычный аккаунт**
(Telethon, `account.checkUsername`). Аккаунт ничего не меняет, только задаёт вопрос. Все пользователи бота
работают через этот один аккаунт по очереди: одновременно идут `MAX_PARALLEL_HUNTS` поисков, остальные ждут
в очереди. Бот предупреждает об этом пользователя.

## Деньги: Telegram Stars
- Цифровые товары в ботах Telegram продаются только за звёзды, и это хорошо: не нужны ни ИП, ни эквайринг.
  Покупатель платит с карты или через Apple/Google Pay внутри Telegram.
- Цены задаются в `.env`: `PACKS=1:10,5:40,15:100` (поисков:звёзд). По умолчанию 1 поиск стоит 10 ⭐,
  5 поисков 40 ⭐, 15 поисков 100 ⭐.
- Звёзды копятся на балансе бота. Вывести их можно через [Fragment](https://fragment.com) в TON
  (вывод доступен через некоторое время после поступления, условия смотрите в @BotFather → Bot → Balance).
- О каждой покупке админу приходит уведомление с `Charge ID`. Возврат делается командой `/refund <charge_id>`.
- Обязательные для платных ботов команды `/terms` и `/paysupport` уже есть.

## Установка
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # заполните BOT_TOKEN, API_ID, API_HASH, ADMIN_IDS
python -m userhunter.login  # один раз: вход в аккаунт-проверяльщик по номеру и коду
python -m userhunter        # запуск бота
```
- `BOT_TOKEN` берётся у [@BotFather](https://t.me/BotFather)
- `API_ID` / `API_HASH` берутся на https://my.telegram.org → API development tools
- `ADMIN_IDS` — ваш Telegram ID (подскажет [@userinfobot](https://t.me/userinfobot))

## 🛠 Админка
Кнопка **🛠 Админка** (видна только админам) показывает пользователей, покупки, выручку, поиски и очередь. Там же:
- **🎯 Автозахват**: найденные в *ваших* поисках юзы сразу занимаются на публичные каналы вашего аккаунта.
- **📋 Занятые каналы** и **🏆 Лучшие находки** (с кнопками «🎯 Занять»).
- `/give <user_id> <N>` начисляет поиски (подарок или компенсация).
- `/refund <charge_id>` возвращает звёзды за покупку.
- `/grab юз…`, `/release юз…` занимают юз на канал или освобождают его.

Админ ищет бесплатно и без лимита проверок.

## Проверка работоспособности
```bash
pip install -r requirements-dev.txt
pytest
```
Тесты гоняют **настоящий** диспетчер aiogram на апдейтах в том же виде, в каком их присылает Telegram.
Bot API и аккаунт при этом подменены. Покрыто: старт, бесплатный поиск, пейволл, покупка (с повторной доставкой платежа
и подделкой цены), возврат попытки, кнопка «Остановить», очередь, маски и слова, проверка с лимитом,
админка, захват, возврат звёзд и кнопки под старыми сообщениями.

## ⚡ Скорость поиска
1. **Быстрый отсев через t.me** (включён по умолчанию). Сначала бот пачками и параллельно смотрит
   страницы `t.me/имя`. Если там есть профиль или канал, юз точно занят. Через аккаунт (медленно, с паузой)
   идут только кандидаты. Ошибка отсева не может выдать занятый юз как свободный: всё сомнительное
   перепроверяет аккаунт. При запуске отсев проверяет сам себя. В логе будет строка
   `Быстрый отсев через t.me включён`. Если t.me недоступен, отсев выключается сам.
2. **Несколько аккаунтов-проверяльщиков**: проверяют параллельно, 3 аккаунта дают примерно втрое
   больше скорости. В `.env`: `SESSION_NAME=checker,checker2,checker3`, затем
   `python -m userhunter.login` (спросит номера только новых аккаунтов).
3. `CHECK_DELAY`: пауза между проверками одного аккаунта. 2 вместо 3 даёт плюс 50% скорости,
   но FloodWait будет чаще.

## Важно
- Telegram ограничивает частоту проверок. При FloodWait бот сам ждёт. Не ставьте `CHECK_DELAY` меньше 2–3 секунд.
  При 3 секундах получается около 1200 проверок в час на всех пользователей, то есть примерно 20–40 поисков в час.
  Если бот станет популярным, это узкое место.
- Используйте **отдельный аккаунт** для проверок: файл `*.session` даёт полный доступ к нему (файл уже в `.gitignore`).
- Бот не занимает юзы за покупателя: тот ставит юз сам. Об этом сказано в `/terms`.
